## NOTES ON SPECIFIC TERMS

- **Seviche** — Getty’s admitted spelling. Do NOT use “Ceviche” even though that is the more common English spelling.
- **Jay Pritzker Pavillion** — double-L. Do NOT use “Pavilion”.
- **Donut / Doughnut** — use BOTH in the same keyword list to catch both search variants.
- **Color Image vs Colour Image** — Getty appears to accept both; US-format assets use Color Image. Default to Color Image for consistency.
- **Arch - Architectural Feature** — always use the compound, never bare “Arch”.
- **Bridge - Built Structure** — always use the compound, never bare “Bridge”.
- **UNESCO - Organised Group** — must be included whenever UNESCO World Heritage Site is used.
- **Frank Gehry / Christopher Wren** — architects accepted as keywords by name; use whenever a building by a named architect is the subject.
- **Ziggurat** — accepted as an architectural form descriptor (used for MI6 building).
- **Accessibility for Persons with Disabilities** — exact long-form required; do not abbreviate.
